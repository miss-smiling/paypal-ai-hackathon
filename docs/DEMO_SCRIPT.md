# Demo Video Script (under 3 minutes)

**Rules:** under 3 minutes, shows the project running on its intended device (the web app on a laptop screen), publicly viewable on YouTube, and no third-party trademarks or copyrighted music. Use no background music. Keep the PayPal logo off screen unless it appears naturally in the approval window.

**Setup before recording**
- Backend running, frontend running, or the hosted URL open in a clean browser window.
- Budget cleared for the session. Browser zoomed to 110% so text is readable.
- Test the full run once. Time it.

## Shot list

| Time | On screen | Narration |
|---|---|---|
| 0:00–0:15 | Title card: "SmartCart AI" | "Shopping online means reading dozens of reviews and comparing prices across tabs. SmartCart does that for you, from one sentence." |
| 0:15–0:40 | Type "ANC headphones under $250 with 30h battery" and press Find | "A team of AI agents reads the request. An intent agent extracts the budget and specs." |
| 0:40–1:05 | Agent activity list, then the decision matrix | "Discovery filters the catalog. The review agent removes fake five-star reviews and scores trust. The top pick is ranked by spec match, trust and value, not sponsored placement." |
| 1:05–1:25 | Point to "2 suspicious review(s) removed" on a card | "Here, two bot-style reviews were removed before trust was scored." |
| 1:25–1:45 | Cart panel: coupon applied, shipping, total | "The price agent applies the best valid coupon. The total is updated before anyone pays." |
| 1:45–2:00 | Set budget to 150 and search again | "The budget agent tracks spending. If the top pick goes over budget, it suggests cheaper alternatives." |
| 2:00–2:30 | Tick "I approve paying…", click "Pay with PayPal", approve in the PayPal sandbox window | "Payment needs explicit approval from the shopper. The order is created with PayPal's Orders API in the Sandbox, so no real money moves." |
| 2:30–2:45 | Back in SmartCart: completed order under "Budget and spending" | "Once PayPal confirms the capture, the order is recorded and spend updates." |
| 2:45–3:00 | Title card with GitHub link and "MIT license" | "SmartCart AI is open source. Thanks for watching." |

## Recording tips
- Practise once. Aim for 2 minutes 40 seconds so there is room.
- Keep the mouse movements slow and deliberate.
- If a live step is slow, cut it in editing rather than narrating over dead air.
- Upload to YouTube with visibility set to **Public**, not Unlisted.
- Title: "SmartCart AI: Agentic Commerce with PayPal (PayPal AI Hackathon 2026)".
